# Security gate: v0 preview site

Owner: `security-engineer`, 2026-11-08. Scope: `dist/`, `public/_headers`, `scripts/check-dist.mjs`, the form client, dependencies and CI changes since `review-setup-and-ci-2026-11-08.md`. The contact function and setup guide were reviewed earlier.

**Tested:** `npm run build` and `check:dist` (pass), 30 mutations of a scratch copy of `dist/` against `check-dist.mjs`, a `SHOW_DRAFTS=true` build in a scratch folder, greps of `dist/` for inline code, comments, source maps, URLs, emails, placeholders and AI, tool and vendor wording, `npm audit`, the lockfile, `.npmrc` and the CI diff. **Not tested:** anything live (headers over HTTPS, the real Turnstile widget under this CSP, browser storage) and `npm audit signatures` (registry unreachable).

**Clean:** `dist/_headers` matches section 2.1 exactly, Turnstile on `script-src` and `frame-src` only. No inline script, `<style>`, `style=` or `on*=`. No comments, source maps, generator tag or analytics. Fonts are self-hosted and there are no external links. The client uses no `innerHTML` or storage and never shows server text: `error` codes map to texts in inert `<template>` elements. The Turnstile URL is a constant, `/thanks/` is a static path with no data in it, and the body follows `contact-api.md`. The honeypot is `aria-hidden`, `sr-only`, `tabindex="-1"`, `autocomplete="off"`. Production text has no AI or tools wording. Vendor names (Cloudflare, Turnstile, Resend) appear only as the required processor disclosure.
