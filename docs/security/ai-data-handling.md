Why this page matters: a buyer with valuable IP will read it line by line. A simulated buyer review (not market evidence) said a vague line such as "AI tools under written data rules" alarms more than it reassures. They want named tools, retention, data location, who at the vendor can read data, the liability cap, and how far a no-AI mode reaches. They also note that "not used for training" is not the same as "not retained".

5. Whether a data processing agreement is signed with each vendor.
6. Whether a no-AI mode is practical, which tools it switches off, and its price.
7. Where customer files are stored outside AI tools (laptop, cloud drive), with encryption and backup.
8. The deletion process and retention period at project end.
9. Liability cap and professional liability insurance status.

## 3. Do not claim until confirmed

- "Your data is never used for training" (needs the written term for every tool in use).
- "Not retained", "zero retention" or "deleted immediately" (most vendors keep inputs for a period, so a no-training term does not mean no retention).
- "Stays in the EU" or "GDPR compliant".
- "No one can read your data" (vendor staff access usually exists in some form).
- "Enterprise-grade", "secure", "encrypted end to end" or any certification.
- "No-AI mode available" before its scope covers built-in CAD features, transcription and email.
- Any vendor name before the plan tier and terms are recorded in the table.
- Any liability or insurance figure.
