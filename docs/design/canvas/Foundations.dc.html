01 / Logo

Route 01, Trace: lockup, symbol and tile

The default logo for the web. It says enclosure plus electronics at a glance and its tile survives 16 px. Route 02, Section, is the fallback if the name loses its N.

Header above 768 px: 32 px
Header below 768 px: 28 px
Minimum: 24 px, 89 px wide

At 390 px the lockup plus four links did not fit, so the links collapse and the header keeps the lockup and one button.

In code

Swap the ink fills for currentColor and keep the pads #FF5A1F, so one component serves light and dark sections.

Never

Recolour, stretch, rotate, outline, shadow or animate the logo. Signal on Steel is 1.47:1, so the pads vanish there.

A name that can change

The name lives in src/config/site.ts only. The symbol carries only the initial N, so a rename redraws the wordmark and nothing else.

02 / Colour

Ink and Paper carry the page. Signal marks the action.

Every colour on the site comes from these tokens. Contrast ratios use the WCAG 2.x formula, rounded down, and two separate programs agreed.

Ink

#0F1B2D, color-ink

Text, dark sections and the logo. 15.79:1 on Paper.

Steel

#6B7686, color-steel

Control borders and dimension lines. Not for small text: 4.20:1 on Paper.

Paper

#F4F5F2, color-paper

The page ground. White is used only for surfaces on it.

Signal

#FF5A1F, color-signal

Fills and shapes. Ink text on it is 5.54:1. Never text on Paper.

Derived steps

Each step keeps the base hue and moves lightness in OKLCH (a perceptual colour space), solved against the contrast targets. Add one only when a component needs it.

The text colour on a Signal fill (on-accent) is always Ink. Muted on paper-200 is 5.03:1 and signal-800 on signal-100 is 7.02:1. Status messages sit on the surface colour with a left rule and an icon, never colour alone.

Signal may be used for

  • Fills and shapes: the logo pads, accent bars and the primary button with Ink text.
  • Anything on Ink, where it is 5.54:1.
  • One primary Signal fill per view.

Signal may not be used for

  • Text on Paper (2.84:1) or on white (3.11:1). Use the link colour.
  • White text on Signal, which is 3.11:1.
  • Thin marks that carry meaning on Paper.
  • A state or chart series told apart by Signal alone.
